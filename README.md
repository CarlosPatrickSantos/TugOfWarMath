# TugOfWarMath
Tug of War Math (Cabo de Guerra Matemático) Desenvolvido por: Carlos Patrick  Sobre o Jogo O Tug of War Math é um jogo de estratégia e agilidade mental desenvolvido na engine Godot 4.4. O objetivo é unir o clássico desafio de "Cabo de Guerra" com a resolução de operações matemáticas rápidas,.
