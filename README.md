Tug of War Math (Cabo de Guerra Matemático)           2026/02/21
Desenvolvido por: Carlos Patrick

Sobre o Jogo
O Tug of War Math é um jogo de estratégia e agilidade mental desenvolvido na engine Godot 4.4. O objetivo é unir o clássico desafio de "Cabo de Guerra" com a resolução de operações matemáticas rápidas, criando uma experiência competitiva e educativa para jogadores de todas as idades.

Como Jogar
Desafio Matemático: Dois jogadores competem em tempo real para resolver contas de adição, subtração, multiplicação ou divisão.

Mecânica de Cabo de Guerra: Cada resposta correta faz com que sua equipe puxe a corda para o seu lado.

Vitória: Ganha a equipe que conseguir puxar o marcador totalmente para o seu campo ou quem tiver a maior vantagem quando o tempo se esgotar.

Principais Funcionalidades
Multiplayer em Rede Local (LAN): Sistema de conexão via IP que permite criar salas (Host) ou entrar em partidas existentes (Join).

Interface Adaptada para Mobile: Teclado numérico customizado com botões amplos (180x180) e layout estilo calculadora (7-8-9 no topo) para facilitar o toque em dispositivos Android.

Modos de Operação: Seleção manual de qual tipo de conta os jogadores desejam enfrentar no menu inicial.

Visual Dinâmico: Cenário colorido com feedback visual imediato do progresso da corda e cronômetro de partida.

Tecnologias Utilizadas
Engine: Godot 4.4 (GDScript).

Protocolo de Rede: ENetMultiplayerPeer para sincronização de dados entre os jogadores.

Versionamento: Git/GitHub para controle de progresso e backup.

Dica do Carlos Patrick: "Este projeto nasceu da ideia de tornar o aprendizado de matemática algo emocionante e competitivo, provando que rapidez de raciocínio pode ser a sua maior força!"
